A theme block must declare the whole catalogue. A missing role silently falls back to the base theme's value — a light surface with dark-theme text, one token at a time. The contract test fails on any gap, in every theme. Re-point, never re-hex. --fold-color-* may only reference a --fold-ref-* primitive (or a color-mix() of one). A literal in the semantic layer is a colour no other theme can follow — also enforced. Radius is the only scale a theme may re-declare: corner softness is a brand axis, and the one scale that changes without moving a box. Type, space, motion and elevation stay theme-invariant — retheming must never re-flow a page.

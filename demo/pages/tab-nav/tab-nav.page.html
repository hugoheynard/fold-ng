A navigation bar styled as tabs — a <nav> whose items go somewhere. Clicking one changes the route: the URL updates and the <router-outlet> renders the matching view. The active item is derived from the URL (so deep links, back and forward all stay in sync) and marked with aria-current="page". Horizontal for a page-level bar, vertical for a sidebar rail — which folds back to a bar on top once its container gets too narrow to hold a rail beside the content (the wrapping fold-nav-layout's job, on its own width).

Does the tab go somewhere? This is your component — it drives routing (URL changes, <router-outlet>, browser history). If instead the tabs toggle layered panels in place on the same URL, use fold-tabs — same look, but the ARIA Tabs widget (role="tablist", arrow keys). Using this navigation bar to fake in-place tabs is an anti-pattern, so the two are separate on purpose.

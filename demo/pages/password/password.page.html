fold-password-field — a password input with a live requirements checklist. It composes fold-input[type=password] with the reveal (eye) toggle, and renders a dot per rule that turns on as the value satisfies it. Rules are injected (regex, a zod safeParse, anything), so the policy is yours; validChange emits when they all pass. Signal-Forms-native.

revealable

valid = {{ valid() }}

A rule is just a label + a predicate (FoldPasswordRule), so any validation style drops in. The default policy is 8+ characters, upper, lower and a digit — override [rules] for your own.

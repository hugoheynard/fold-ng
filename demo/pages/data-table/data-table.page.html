fold-data-table — a controlled, presentational roster table. The parent supplies already-sorted/paged rows, a columns definition, and one <ng-template foldCell> per column; the table owns the chrome — sticky sortable header, per-row tone accents, click/focus, the mobile card layout, and the loading + empty states. Accessible by construction: the identity column is a <th scope="row">, sort rides on aria-sort, rows answer Enter and Space, and caption names the table for assistive tech.

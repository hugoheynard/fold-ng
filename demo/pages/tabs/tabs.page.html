The in-page ARIA Tabs widget: a role="tablist" that switches layered panels without navigating. Arrow keys move between tabs (roving tabindex — only the active tab is in the Tab order), Home/End jump to the ends, and each tab is wired to its panel (aria-controls ↔ aria-labelledby).

Switching panels in place? This is your component. If the tabs instead navigate between routes/views, use fold-view-nav — same look, but <nav> + aria-current. Using the tabs pattern for navigation is an anti-pattern, so the two are separate on purpose.

The one opt-in of the shell scroll system. With fold-app-shell owning the page scroll, a layout that needs an independently-scrolling area — a split list/detail, a data-table body, a sticky sidebar — marks it with [foldScrollRegion] instead of hand-rolling overflow. It sets the three foot-guns (overflow, min-*: 0, overscroll-behavior: contain) and the thin house scrollbar, and registers with the shell so a modal overlay freezes it too (the scroll owner is an inner box, not body). Axis: block (default), inline, both.

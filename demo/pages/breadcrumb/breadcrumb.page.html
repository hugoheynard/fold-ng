A hierarchical trail of links to the current page. Data driven — pass [items]; each crumb links by an Angular routerLink or a plain href, so it works in a router app and degrades to anchors without one. The last item is the current page (aria-current="page"), never a link. It's a navigation landmark; chevrons are decorative.

Tarte au citron meringuée

Read the two together: the trail says where, the heading says what. With the default [currentPage]="true" the product name would appear twice — once as a crumb a screen reader announces as the current page, once as the heading that actually is.

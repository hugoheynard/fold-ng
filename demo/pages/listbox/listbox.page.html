The styleable select family — three ways to pick from a list, same tokens and box chrome. fold-listbox (one value) and fold-multiselect (a set) are built on fold-popover for a fully styleable panel; fold-select wraps a native <select> for a mobile-native, zero-JS default. Pick a tab.

A single-select on the native top layer. Options can be anything you project — an icon, a second line, a status — which is the reason to reach for it over the native <select>. Full keyboard, role="listbox" with aria-activedescendant, and Signal Forms (value: string).

The trigger stays in the normal flow; opening hands the panel to the browser's top layer, so it escapes any overflow / z-index. The role="listbox" holds focus and points aria-activedescendant at the active row — the rows themselves stay dumb, each computing its own selected / active state from the owner. Selecting commits the value and closes, returning focus to the trigger.

The same popover and rows, but the value is a set (readonly string[]): activating a row toggles it and the panel stays open. A separate component, not a multiple flag, so the Signal-Forms value type stays honest. aria-multiselectable; the trigger summarises the picks.

Structurally identical to the listbox — same top-layer panel, same roving keyboard core (shared via a FOLD_LISTBOX_OWNER token). The only differences live at the edges: aria-multiselectable, activation toggles membership instead of committing, and the panel is never closed on a pick — so several choices are one interaction.

A thin wrapper around a real <select> — the lighter default. Not styleable inside the popup and rows are plain text, but you get the OS's keyboard, focus and a native mobile wheel for free. Reach for it unless you need custom rows.

No popover, no ARIA to run: fold-select only restyles the closed control (box + caret) and forwards [value] / (change) to Signal Forms. When it opens, the operating system paints the option list — outside your DOM, so it can't be styled, but keyboard, focus and the touch wheel are all handled for you.

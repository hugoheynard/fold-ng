fold-inline-confirm — an in-place “are you sure?” guard, no modal. The host projects the trigger (a real foldButton / fold-button-icon); on activation it is replaced, in the same slot, by a confirm/cancel row. Three families: simple (confirmed emits ""), type-to-confirm ([match] — the button unlocks once the text matches), and secret (password — a masked field that emits the typed value for the server to check). Escape cancels, focus moves into the affordance and back to the trigger, labels are overridable (provideFoldInlineConfirmLabels).

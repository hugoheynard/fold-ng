# Roadmap 1.0.1 — `@sh3pherd/ui`

The lib sits at **~8.4/10** (Technique 9 · Design 8.5 · Practices 8.5 · DX 8.5 ·
Tests 7.5). Foundations are ~9; what's missing is **finish + proof**. This is the
per-component path to a **9.5 average** — the two big levers are the P0 ship
blockers (they drag a component below its cluster) and the cross-cutting Tests /
i18n / proof work at the bottom. app-shell's own 8.5→9.5 slice is called out first.

> **Format (gallery-parseable).** Each item is
> `- [ ] `` `` `Pn·kind` `` `` **Title** — detail.`
> **Priority** `P0` blocker · `P1` polish · `P2` trigger-gated (do on the 2nd real use).
> **Kind** `a11y` · `i18n` · `test` · `depth` · `dx` · `docs`.
> **Status** `[ ]` todo · `[x]` done. A component heading carries its score
> `DX/Tests/Docs` (🟢🟡🔴) and, where rated, a /10.

## Shell & scaffolding

### `sh3-app-shell` — 🟢🟢🟢 · **8.5/10**

Structure + decoupling are big-lib grade (pure structural, `data-attr` +
var-contract elevation, no `:host-context`, strictTemplates-gated). Gap to 9.5:

- [ ] `P1·a11y` **Rails as named landmarks** — `.rail-primary`/`.rail-secondary`
      are bare `<div>`s; add `railPrimaryLabel`/`railSecondaryLabel` →
      `role="navigation"` + `aria-label`. Pairs with the shipped skip-link.
- [ ] `P1·a11y` **Secondary rail reachable on mobile** — below the breakpoint only
      the primary rail returns (the drawer); a bi-rail app loses `railSecondary`.
      Stack both in the drawer, or a segmented toggle inside it.
- [ ] `P1·test` **Visual-regression snapshots** — the mode-combos jsdom can't
      exercise: drawer open/closed, elevated rail (`:has` gutter), footer
      `scroll`/`pinned`, `header`/`footerLayout` full, mobile collapse. The crop
      bug shipped for lack of exactly this.
- [ ] `P2·depth` **Extract `Sh3Drawer*` primitive** — the inline drawer mechanics
      (`mobileNavOpen`, `drawerOpen`, `Escape`, widen-reset, focus-trap gating).
      _Trigger: a 2nd off-canvas drawer (filters/detail)._
- [ ] `P2·docs` **Decide right-rail / tertiary-rail** — no persistent right rail
      (assume `sh3-aside-layout` + panels?), tertiary-rail as a token vs a 3rd slot.

### `[sh3Elevated]` — new (from the elevation refactor)

- [ ] `P2·depth` **Named elevation scale** (`sm|md|lg`) — boolean today; the level
      is dialed via `--sh3-surface-shadow`/`-radius` in scope. _Trigger: ≥2 named
      levels (a raised card vs an overlay dialog with different shadows)._

### `[sh3Surface]` — 🟢🟢🟢 · Ship-ready

- [ ] `P2·depth` **Own the background** — the last step to an M3-style surface
      (surface = {bg + text role}), so `sh3Elevated` becomes fully self-contained
      (no "bring your own bg" footgun). _Trigger: a 2nd surface-without-its-own-bg._

## Ship blockers (P0 — each drags a component below its cluster)

### `sh3-button-icon` — 🔴🟡🟡

- [ ] `P0·a11y` **`aria-pressed` only for real toggles** — momentary buttons are
      announced as pressed toggles. Gate `aria-pressed` behind a `toggle` intent.
- [ ] `P1·dx` Align naming with `sh3-button`; add `@example`.

### `sh3-paginator` — 🟢🟢🟡

- [ ] `P0·i18n` **French, non-overridable a11y strings** → `input()`s with English
      defaults (`perPage`/`of`/`empty`/`prev`/`next`/`page`).
- [ ] `P1·docs` Gallery page.

### `sh3-panel-host` / `sh3-panel-header` — 🟢🟢🔴

- [ ] `P0·i18n` **French "Fermer"** → `closeLabel` (default `"Close"`).
- [ ] `P0·a11y` **Focus-trap does not `inert` the background** — a keyboard-only
      trap; a screen-reader virtual cursor still reaches behind. Add a real modal
      barrier.
- [ ] `P1·dx` Fold the close `<svg>` into `<sh3-icon name="close">`; add README rows.

### `sh3-file-dropzone` — 🟡🟢🟡

- [ ] `P0·i18n` **French default copy** → inputs with English defaults; README row.

### `sh3-tab-nav` — 🟢🟡🟢

- [ ] `P0·a11y` **No tab a11y contract** — add `role="tab"`/`role="tablist"` +
      `aria-selected`.
- [ ] `P1·dx` `font-size: 10px` → a text token.

### `sh3-tab-layout` — 🟢🟡🟢

- [ ] `P0·dx` **`as unknown as` in the spec** — remove the strict-TS breach.

## Cross-cutting (lib-wide — the average's biggest levers)

### Tests (7.5 → 9)

- [x] `P1·test` **Dead-binding gate** — `lint:ui-templates` runs Angular
      `strictTemplates` (ngtsc) over the lib + gallery, wired into CI, with a bite
      fixture. Catches removed-input / missing-property template errors `tsc`/Vite
      miss. _(First template-level proof.)_
- [ ] `P1·test` **Visual-regression baseline** (Playwright / Vitest-browser) per
      component × dark/light — the theme flip is claimed, never pixel-verified.
      _(Includes the app-shell mode-combos above.)_
- [ ] `P1·test` **axe-core automation** in the panel/overlay specs (role,
      `aria-modal`, focus order, Escape) — not just "it renders".
- [ ] `P1·test` **Coverage floor** in CI; fill the thin components (tab-nav, app-shell).

### i18n (Practices / DX 8.5 → 9)

- [ ] `P1·i18n` **Sweep every user-facing / `aria-label` string → `input()`** with
      an English default (paginator, panel close, dropzone, menu, range-slider).
      The app supplies French once at the call sites.

### a11y depth (Design 8.5 → 9)

- [ ] `P1·a11y` `inert` the background behind an open panel (see panel P0).
- [ ] `P1·a11y` **Reduced-motion sweep** — gate remaining slide/fade behind
      `prefers-reduced-motion` (menu width, panel slide, hero glow; toast already does).
- [ ] `P2·a11y` Reconsider the px type scale — a `rem` opt-in for consumers whose
      root ≠ 14px, so user-zoom works.

### Discipline (Practices 8.5 → 9)

- [ ] `P1·dx` **Retokenise hardcoded px spacing + `0.18s` motion** to
      `--sh3-space-*` / `--sh3-motion-*`, then a lint guard so it's enforced like colour.

### Proof + release (DX / Design → 9.5)

- [ ] `P1·dx` **A 2nd consumer** (even a tiny playground app) — the API is
      validated by one app today; a 2nd reveals hidden assumptions.
- [ ] `P1·dx` **Storybook** (or a docs playground) so components are browsable.
- [ ] `P1·dx` **Real semver + CHANGELOG**; graduate from `0.0.0`. Wire the package
      into the repo quality gates. _Started: `lint:ui-templates` is the first CI gate._

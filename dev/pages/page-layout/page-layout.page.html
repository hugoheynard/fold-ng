The vertical scaffold every page wraps its content in: an optional icon + title header with [description] and [pageActions] slots, then a body that stacks its children on a steady rhythm. It owns the page gutter, not the width — it fills whatever it is given, supplying the themed margins via one token, --fold-page-gutter. Narrowing a block to a readable measure is the content's job, never the page's. This very page is a fold-page-layout.
